# ISP-Network-Simulation-and-Optimization
I developed a graph-based system to simulate and optimize Internet Service Provider (ISP) networks. This project involved implementing Dijkstra’s algorithm to determine the most efficient paths between routers and building a Minimum Spanning Tree (MST) to minimize network cost while ensuring connectivity. Leveraging Python’s advanced libraries and data structures, I used priority queues for pathfinding and graph traversal algorithms to check connectivity and identify network loops. I designed the system to allow dynamic adjustments, such as adding routers or changing edge weights and ensured its robustness through rigorous testing. The project also included creating visualizations for network paths and weights, which improved clarity and allowed stakeholders to assess routing efficiency effectively. This work demonstrates my ability to apply complex algorithms, manage data-intensive systems, and develop scalable solutions, aligning directly with CMT’s emphasis on troubleshooting, scalability, and system optimization.
